# 🎨 AI Image Generator
An AI Image Generator built with Python, Streamlit, and Stable Diffusion 2.1. Enter a text prompt and generate an AI-generated image.

# ✨ Features

- 📝 Enter a text prompt

- 🎨 Generate AI images

- 🤖 Powered by  Diffusion

- 🖥️ Simple Streamlit web interface

# 🛠️ Technologies
- Python

- Streamlit

- PyTorch

- Hugging Face Diffusers

- Transformers

- Diffusion

# 📦 Installation

1. Clone the repository
git clone -<https://github.com/srudhyasankaranarayanan/ImageGenerator>
cd AI-Image-Generator

2. Install dependencies
pip install -r requirements.txt

3. Run the application
streamlit run app.py

# 🚀 Usage

- Open the Streamlit application.

- Enter your image description in the prompt box.

- Click Generate Image.

- Wait for Stable Diffusion to generate the image.

# Example Prompt

A cute cat sitting in a beautiful garden

# 🤖 Model

This project uses the Hugging Face model:
stabilityai/stable-diffusion-2-1-base
